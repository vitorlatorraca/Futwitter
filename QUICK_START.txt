═══════════════════════════════════════════════════════════════
  🚀 HOW TO RUN THE PROJECT - QUICK GUIDE
═══════════════════════════════════════════════════════════════

❌ ERROR: "ERR_CONNECTION_REFUSED" 
This means the server is NOT running!

═══════════════════════════════════════════════════════════════
STEP 1: Check .env file
═══════════════════════════════════════════════════════════════

Create a file called ".env" in the project root with:

DATABASE_URL=postgresql://user:password@host:port/database
PORT=5001
SESSION_SECRET=your-secret-key-here

═══════════════════════════════════════════════════════════════
STEP 2: Run Database Migration
═══════════════════════════════════════════════════════════════

IMPORTANT: Execute this SQL in your PostgreSQL database:

SQL to execute:
───────────────────────────────────────────────────────────────
DO $$ BEGIN
    CREATE TYPE news_content_type AS ENUM ('TEXT', 'VIDEO');
EXCEPTION
    WHEN duplicate_object THEN null;
END $$;

ALTER TABLE news ADD COLUMN IF NOT EXISTS video_url TEXT;
ALTER TABLE news ADD COLUMN IF NOT EXISTS content_type news_content_type DEFAULT 'TEXT';

CREATE INDEX IF NOT EXISTS idx_news_content_type ON news(content_type);
CREATE INDEX IF NOT EXISTS idx_news_video_url ON news(video_url) WHERE video_url IS NOT NULL;
───────────────────────────────────────────────────────────────

Or run via file:
  psql $DATABASE_URL -f migrations/add_video_support_to_news.sql

═══════════════════════════════════════════════════════════════
STEP 3: Run the Server
═══════════════════════════════════════════════════════════════

In PowerShell:
  npm run dev

In CMD (Windows):
  npm run dev:win

═══════════════════════════════════════════════════════════════
STEP 4: Verify it Worked
═══════════════════════════════════════════════════════════════

You should see in the terminal:
  "serving on port 5001"

Then access in the browser:
  http://localhost:5001

═══════════════════════════════════════════════════════════════
🔍 IF IT STILL DOESN'T WORK:
═══════════════════════════════════════════════════════════════

1. Check the terminal console - copy the error message
2. Verify if PostgreSQL is accessible
3. Verify if DATABASE_URL is correct
4. Try running: npm run db:push
